## 🧑‍🔧 Infrastructure Overview: 5 เสาหลักแห่งความสำเร็จ
โครงสร้างที่ผ่านการกลั่นกรองมาอย่างดี:

| Component | Role | Responsibility |
| :--- | :--- | :--- |
| **`cmd/`** | 🚀 ตัวสั่งการ | จุดเริ่มต้นของระบบ (Entry Point) |
| **`docs/`** | 🧑‍⚖️ สถาปนิก | กฎระเบียบและมาตรฐานปฏิบัติสำหรับทีม |
| **`services/`** | 🧑‍💻 วิศวกร | งานเฉพาะทาง (Scrapers, Schedulers) ที่ปรับจูนจนนิ่ง |
| **`data/`** | 🧑‍🔬 นักวิจัย | คลังเก็บผลลัพธ์และทรัพย์สินทางปัญญาที่ปลอดภัย |
| **`templates/`** | 🧬 นักพันธุศาสตร์ | DNA แม่แบบสำหรับขยายผลไปสู่ 12 โครงการ |
| **`scripts/`** | 🥷 สายลับ | ระบบอัตโนมัติ (Automation/Distribution) ที่รวดเร็ว |

## 🤖 AI Execution Directive: มาตรฐานการสั่งงาน
เพื่อให้ AI ทุกตัวทำงานบนโครงสร้าง TNH_AI_Master_Template อย่างเป็นเอกภาพ:

1. **Zero-Garbage Protocol:**
   - ห้ามสร้างไฟล์ขยะ (Dead code, .log, .tmp) หากพบต้องสั่งลบทิ้งทันที
   - โค้ดต้องสะอาด สอดคล้องกับ `Tnh_manifesto.md`
2. **Standardized Directory Structure (5ส):**
   - การแก้ไขโค้ดต้องอิงตามลำดับชั้น: `cmd/` (Entry), `internal/` (Logic), `scripts/` (Tools)
   - ห้ามประกาศไฟล์ `main.go` ซ้ำซ้อนเด็ดขาด (Entry point หลักอยู่ที่ `cmd/main.go` เท่านั้น)
3. **Execution Standards:**
   - ก่อนรันงาน: ต้องรัน `bash scripts/init.sh` เพื่อตรวจสอบสภาพแวดล้อม
   - การสื่อสาร: ให้เน้นความกระชับ ตรงประเด็น และระบุตำแหน่งไฟล์ (Path) เสมอ
4. **Naming Convention:**
   - ใช้พิมพ์เล็กทั้งหมด (lowercase) สำหรับชื่อไฟล์และโฟลเดอร์ เพื่อป้องกันบั๊กพิมพ์เล็ก-พิมพ์ใหญ่ใน Linux/Termux

## ⚖️ Governance & Compliance: ความโปร่งใสคือ Default
ในโลกของ Enterprise AI, **ความน่าเชื่อถือสำคัญกว่าทุกอย่าง:**
1. การเชื่อมต่อทุกอย่างต้องผ่านการรับรองตาม **`SYNC_POLICY.md`**
